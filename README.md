# 🏥 California Healthcare Access Gap Analysis

**Portfolio Project | Health Data Analyst**

## Overview
Identified California counties that qualify as "healthcare deserts" by analyzing
931 licensed facilities across all 58 counties against population data.

## Key Findings
- 11 out of 58 CA counties fall below the access threshold (2.1 per 100k)
- Rural northern and central CA are the most underserved regions
- Significant urban-rural access gap identified
